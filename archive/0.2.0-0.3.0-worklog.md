Numerics work (all measured in /tmp debug runs, final numbers in
experiments/logs/2026-10-18-conformance.log):

- Implemented src/core/solver.js: the numeric oracle for 0.0.0 section 5
  (forces, semi-lagrangian advect_vel, poisson rhs with S, projection,
  apply_grad, compute_flux, donor-cell advect_scalar, scenarios, exact dye
  patches, wall patches, ledger).
- Instability 1: the still box exploded at any jacobi iteration count. Root
  cause: the checkerboard mode is an exact eigenvalue -1 of jacobi on the
  all-neumann closed box (residual stalls at 25.77 of |b|~400 after 600 iters,
  p oscillates in a period-2 cycle). Fix: red-black gauss-seidel (omega=1; sor
  1.7/1.9 measured divergent on the singular system).
- Instability 2: still box with stratification still churned. Root cause: the
  section 5.6 force (rho_ref - rho) re-injects the uniform part through the
  walls; projection residual then slowly evacuates/overpacks boundary mass and
  buoyancy amplifies. Fix: mean-subtracted gravity (rho_mean - rho), which makes
  the "projection removes the uniform part" claim exact. Uniform box now exactly
  still (max|vel| = 0.0, drift 0.0, 500 frames).
- Instability 3: dam break ran away (maxVel doubling ~2 steps at 64^2). Three
  compounding causes, each verified: (a) debug runs without substeps hit the
  flux clamp, which breaks divergence-freeness (fixed by proper substepping in
  the app loop; clamp stays as safety net); (b) liquid had no resistance to
  compaction — added the minimal anti-overpack expansion source S (section 5.4
  liquid form) to the rhs; (c) 20:1 density ratio (liquid 1.0 in 0.05 ambient)
  is stiff — scenario ambient is now 0.3 (~3:1) until 0.5.0 gives gas rho*.
  Final dam at 64^2, K=60, substepped: maxDiv 5.0e-1, zero overpack, no
  negatives, drift 8.5e-9.
- Conservation floor identified: f32 field storage rounds every cell update, so
  closed-box drift is a random walk at ~eps32 scale (3.7e-8 rel / 1200 frames),
  identical in spirit on gpu and cpu. Acceptance wording updated (1e-7 bar);
  the 0.3.0 plan's "exactly 0.0" was not achievable as written.
- One real bug found by the solid-rotation unit test: advect_scalar read the
  east/north flux from the wrong texel (row stride instead of column stride),
  inventing 22x mass in 200 steps. Fixed; single-step conservation now 5e-7
  (f32 rounding), 200-step rotation drift 6.6e-8, dye total exact.
