# 0.7.0 t4 — static obstacles, moving colliders & t3 review worklog (2026-10-24)

## 1. Review of 0.7.0 t3 (`emitters`) and surrounding GPU/engine plumbing

Before implementing `0.7.0 t4`, audited `src/core/emitters.js`, `src/core/config.js`,
`src/core/probes.js`, `src/core/solver.js`, `src/core/stats.js`, `src/gpu/solver.js`,
`src/gpu/shaders.js`, and `examples/demo.js`. Found and resolved six issues:

1. **Unused `paramsOff.emitters: 96` slot (`src/core/config.js`)**: `0.7.0 t3` passes emitter
   slots through a dedicated storage buffer rather than the uniform array, leaving `emitters: 96`
   dead in `paramsOff`. Removed.
2. **Stale `defaultValue` when `setEmitter` switches direction mode (`src/core/emitters.js`)**:
   `defaultValue(cfg, KIND_MOMENTUM, dirMode)` returns `200` for angle mode and `1` (unit scale
   over `(vx, vy)`) for vector mode. Calling `addEmitter({ kind: "momentum", x, y })` (`s.value =
   200`) followed by `setEmitter(id, { vx: 80, vy: 40 })` kept `s.value = 200`, multiplying the
   vector by `200×` (`(16000, 8000)` instead of `(80, 40)`), and the reverse transition scaled
   angle mode down to `1`. Added `s.hasValue` tracking on each slot so `set()` re-derives
   `defaultValue(cfg, s.kind, s.dirMode)` whenever `kind` or `dirMode` changes on a slot whose
   caller never supplied an explicit `value`, while preserving explicit `value` overrides.
3. **Probe validity across interleaved readbacks & grid shrinks (`src/core/probes.js`,
   `src/gpu/solver.js`)**:
   - Adding a new probe (or recycling a freed slot) after an earlier probe readback had set
     `table.sampledFrame >= 0` allowed `sample()` to immediately return `valid: true` with stale
     / zero buffer data from before the slot existed. Added `s.bornFrame` (passed `frameCount`
     on GPU `addProbe`) and gated `sample()` on `table.sampledFrame > s.bornFrame`, resetting
     `bornFrame = -1` on `invalidate()`.
   - Shrinking the grid via `resize(newN)` rebuilt `pool.probes` without clamping existing probe
     coordinates into `[1, newN]`. Exported `syncConfig(table, cfg)` in `src/core/probes.js` and
     called it inside `gpu/solver.js` `resize(newN)`.
4. **Wall brush bounding-box corner overwrites (`src/core/solver.js`, `src/gpu/solver.js`)**:
   `buildWallPatch` encoded `0` both for "outside the disc" inside the `(2R+1)×(2R+1)` bounding
   square and for "erase", and `paintWall` called `writeTextureRect` directly on `pool.flags`.
   Painting a round wall disc next to an existing wall erased the 4 corners of the patch square
   outside `r^2`, and also cleared `flags.g` / `flags.b` phase bytes inside the rectangle.
   Changed `buildWallPatch` to encode `0` = no-op (outside disc), `1` = paint static wall, and
   `2` = erase static wall; updated CPU `applyWallPatch` and GPU `paintWall` (single
   `writeTextureRect` of `flagsMirror` + `runPrimePhase` to restore `flags.g`/`flags.b` and live
   moving-collider bits).
5. **Transient `paintDye` uniform slots (`src/gpu/solver.js`)**: `paintDye` left `cfg.paintX..H`
   non-zero after submitting its patch encoder. Zeroed `paintX..H` immediately after submission
   so shared transient uniform slots `8..11` never leak into subsequent passes.
6. **Blocked-cell `maxDiv` & hotkey UI sync (`src/core/stats.js`, `src/gpu/shaders.js`,
   `examples/demo.js`)**: guarded `maxDiv` in `motionTotals`, `statsReduceA`, and `toDisplay`
   mode 4 on `(fl.r | fl.b) == 0` so blocked cells adjoining open velocity faces are not counted
   as fluid divergence; synced `#scenario` and `#status` in `examples/demo.js` `refreshMeters` so
   `n` / `[` / `]` keyboard shortcuts update the demo readouts within 200 ms.

## 2. 0.7.0 t4 — Static Obstacles & Moving Colliders

### `flags.r` Bit-Packing & Legacy `255` Compatibility

`flags` (`rgba8uint`, `(N+2)×(N+2)`) keeps `flags.g` = phase enum (`0..5`) and `flags.b` = frozen
solid mask (`0|1`), while `flags.r` now bit-packs geometry and moving-collider delta state:

- Bit `1u`: static wall (`setObstacles`, `paintWall`, `paintObstacle(..., "wall")`)
- Bit `2u`: active moving collider on the current step
- Bit `4u`: `newlyOccupied` (`curColl && !wasStepped`) — cell entered by a collider since the
  previous simulated step
- Legacy `255u`: preserved across `colliderMask` and `phaseEos` (`isStatic = (r & 1u) != 0u`,
  `isCollider = ((r & 2u) != 0u) && (r != 255u)`) so existing tests that write `255` directly
  into `flags[i]` keep exact static-wall behavior.

Projection (`poissonRhs`, `projectStep`, `applyGrad`, `mgCoarsen`) and `freezeVel` test
`fl.r > 0u` or `(fl.r | fl.b) > 0u`, while scalar transport (`computeFlux`) zeroes flux across
static walls (`(fl.r & 1u) != 0u || fl.r == 255u`) and frozen solid cells (`fl.b > 0u`) and
allows prescribed face velocity across active moving colliders (`fl.r & 2u`) to transport scalar
mass/energy without evacuating vacuum pockets ahead of an advancing body (`7703453`). `conduction` `wallCool` checks `(fl.r & 1u) > 0u` (`isStaticWall`) so
moving colliders are thermally insulating rather than acting as chilled domain walls, and
`phaseEos` clears bit `4u` (`select(prevFl.r & 3u, 255u, prevFl.r == 255u)`) at the end of every
substep once the step has integrated over the mask.

### Preallocated Collider Table (`src/core/colliders.js`)

- Created `Fluid.core.colliders` (`MAX = 32`, `STRIDE = 16`, `HEADER = 16`, `LEN = 528` floats =
  `2,112 B`), allocated once per solver in `pool.colliders` (`src/gpu/fields.js`).
- Zero per-frame heap allocations: `add`, `move`, `set`, and `remove` mutate preallocated slot
  records in place and pack `table.upload`:
  - Header `[0..3]`: `[live, maxSlotPlus1, movingCount, peakSpeed]`
  - Slot `16 + id * 16`: `[x, y, shape, p0, p1, vx, vy, x0, y0, x1, y1, 0..0]`
    (`shape = 1` circle with `p0 = r^2, p1 = r`; `shape = 2` axis-aligned box with
    `p0 = w/2, p1 = h/2`).
- Also provides `applyObstacleMask(flags, texW, texH, maskArray, w, h)` (nearest-neighbor mapping
  from `w×h` into `1..N` preserving bits `2|4`) and `paintWallDisc` / `parsePaintKind`.

### GPU & CPU Pass Schedule (`src/gpu/shaders.js`, `src/gpu/passes.js`, `src/gpu/solver.js`, `src/core/solver.js`)

Four inline WGSL compute shaders were added (all using `vec4<f32>`/`vec4<u32>` storage stores and
plain loop increments for `wgsl_reflect` compatibility):

1. `colliderMask` + `copyFlags`: updates bits `2u | 4u` in `pool.flags` via `pool.flagsTmp`
   without touching static bit `1u` or phase bytes `g, b` (avoiding `copyTextureToTexture`, which
   `experiments/mock-device.js` omits). Dispatched **only** when `maskDirty || (live === 0 &&
   hasGpuMask)` — idle tables and stationary colliders after their initial stamp add **zero**
   GPU dispatches per frame.
2. `colliderVel`: appended inside `encodeVelAdv` (`io.v = 1 - io.v`) **only** when
   `movingCount > 0`. After semi-Lagrangian / MacCormack velocity advection and right before
   `poissonRhs` + multigrid projection, faces adjacent to active moving colliders receive the
   clamped rigid-body `(vx, vy)` (averaging overlapping slots `0..maxSlotPlus1 - 1`), while
   domain boundary, static-wall (`(fl.r & 1u) != 0u`), and frozen-solid (`fl.b > 0u`) faces stay
   strictly `0`. Projection then makes the surrounding open fluid divergence-free around the
   advancing rigid boundary, creating a physical bow wave and trailing wake without touching `m`.
3. `paintSolid`: implements `"solid"` (`mode = +1`, cools open fluid with `m >= mEps` to
   `max(TEps, TMelt - 15)` and records extracted enthalpy in `therm.a` / `heatOutE`) and `"erase"`
   thaw (`mode = -1`, warms frozen cells `fl.b > 0u` to liquid at `max(TEps, TMelt + 2)` using
   `cSol * TMelt + Lf + cLiq * (T - TMelt)` and records added enthalpy in `therm.b` / `heatInE`),
   followed by `runPrimePhase()` (`phaseEos` + `freezeVel`).
4. `toDisplay`: distinguishes static walls (`(fl.r & 1u) != 0u`) from moving colliders
   (`isCollider`), rendering moving colliders in slate-steel with a 1-px amber rim in
   `solidOverlay` and amber-gold in modes 5 (`flags`) and 7 (`phase`).

### Engine Surface & Demo Playground (`src/api/engine.js`, `examples/demo.html`, `examples/demo.js`, `README.md`)

- Exposed `setObstacles`, `paintObstacle`, `addCollider`, `moveCollider`, `setCollider`,
