`experiments/input.js`, `experiments/engine.js`, and `archive/0.7.0-bindkeys-worklog.md`.
Found and fixed four edge cases:

1. **Non-`Element` `e.target` guard (`src/app/input.js`)**: `isFormTarget` previously called
   `target.closest(...)` whenever `target.tagName` existed or without checking
   `typeof target.closest === "function"`, throwing on `window`, `document`, or lightweight

   `removeEventListener` on partial targets.
2. **Custom `keyTarget` blur cleanup (`src/app/input.js`)**: `blur` was only bound on `window`,
   so binding keys to a focusable container `keyTarget !== window` left `state.keys` stuck when
   focus left `keyTarget` inside the same window. Added `blur` listener on `keyTarget` as well.
3. **Engine-routed reset/resize shortcuts (`src/app/input.js` + `src/api/engine.js`)**: pressing
   `r`, `n`, `[`, or `]` under `attachInput` / `bindKeys` previously called `solver.reset()` and
   `solver.resize()` directly, bypassing `engine.reset()` and `engine.setGrid()` (leaving the
   engine canvas unresized and skipping the pacing gate). Added `opt.onReset` / `opt.onResize`
   hooks in `input.js` and wired `engine.js` to route them through `reset()` / `setGrid()`,
   and forwarded `opt` in `createKeys(canvas, cfg, solver, setViewMode, opt)`.
4. **Default target on `sim.bindKeys()` (`src/api/engine.js`)**: `sim.bindKeys()` with an
   omitted argument now defaults to `window`, while `sim.bindKeys(null)` continues to return
   `null` cleanly.

## 2. 0.7.0 t3 — Emitter Architecture & Exact Conservation-Ledger Accounting

### Preallocated Table (`src/core/emitters.js`)

- Created `Fluid.core.emitters` (`MAX = 32`, `STRIDE = 16`, `HEADER = 16`, `LEN = 528` floats =
  `2,112 B`), isomorphic for browser classic `<script>` and Node CommonJS.
- Zero allocations in `step()` / `update()` / `render()`: `create(cfg)` preallocates all 32 CPU
  slot records plus the `Float32Array(528)` GPU upload buffer; `add`, `move`, `set`, and `remove`
  mutate slots in place and maintain header counters `[live, maxSlotPlus1, momentumCount,
  scalarCount, massDrainCount]`.
- Slot layout (`16 + id * 16`):
  `[x, y, invR2, r2, kind, val, dr, dg, db, vx, vy, enthalpy, x0, y0, x1, y1]`.
- Quadratic radial falloff (`t = max(0, 1 - d2 * invR2)`, `w = t * t`, `amt = (val * dt) * w`)
  uses pure `+`/`-`/`*` arithmetic so CPU `Math.fround` and WGSL `f32` agree down to rounding.

### Six Emitter Kinds & Phase Semantics

All scalar/thermal emitters skip static wall cells (`flags.r > 0`) and evaluate on cell centers
`(x - 0.5, y - 0.5)` inside `1..N`:

- `dye` (`1`): injects mass `amt`, tracers `dr/dg/db = c * amt` (`c in [0, 1]`), and enthalpy
  `amt * h(T)` (`TAmb` by default, or optional `target` K).
- `heat` (`2`): on cells with `m >= mEps`, adds sensible/latent energy `amt` capped at optional
  `m * h(target)` ceiling.
- `cold` (`3`): on cells with `m >= mEps`, removes energy `amt` down to a liquid-branch floor
  (`TMelt + 2` by default, strictly above `E2 = cSol * TMelt + Lf` so `cold` cools without
  crossing into solid ice).
- `momentum` (`4`): applied in `forces(dt)` on open staggered `u` `(x - 1, y - 0.5)` and `v`
  `(x - 0.5, y - 1)` faces where neither adjacent cell is static wall or frozen solid; zero
  mass/tracer/energy ledger delta.
- `drain` (`5`): removes mass `amt` from cells with `m > 0`; if `amt >= m`, zeroes
  `m, dr, dg, db, E` cleanly to vacuum (`T = TAmb`), otherwise scales `m, dr, dg, db, E` by
  `1 - clamp(amt / m, 0, 1)` clamped `>= 0` so specific enthalpy and tracer ratios are preserved
  without negative roundoff.
- `freeze` (`6`): cold sink on cells with `m >= mEps` whose enthalpy floor is clamped below
  `E1 = cSol * TMelt` (`clamp(TMelt - 25, TEps, TMelt - 1)` by default), extracting sensible +
  latent fusion heat `Lf` so the subsequent `phaseEos` + `freezeVel` pass drives `phi_l -> 0`,
  sets `PHASE_SOLID`, zeroes face velocities, and logs latent/momentum phase counters.

### Exact Conservation-Ledger Closure (CPU + Async GPU Readback)

1. **Sterbenz-exact cell deltas**: every modified channel logs the exact `f32` difference
   between stored states (`vNew - vOld` for injection, `vOld - vNew` for removal) rather than
   the nominal `amt`, capturing `f32` rounding and vacuum/floor clamps identically to the cell
   field reduction.
2. **Thermal channels (`heat`, `cold`, `freeze`)**: accumulate `eNew - eOld` into `therm.b` and
   `eOld - eNew` into `therm.a`, flowing directly through the existing Kahan `statsReduceA` /
   `statsReduceB` reduction into `heatInE` / `heatOutE` with zero extra passes.
3. **Mass & tracer channels (`dye`, `drain`)**: a single-workgroup `emitterTally` pass
   (`@workgroup_size(64)`) runs immediately before `applyEmitters` when `massDrainCount > 0`,
   walking only the union of active `dye`/`drain` bounding boxes (first-box ownership prevents
   double counting across overlapping emitters) and Kahan-accumulating the 10 injection/removal
   totals into `pool.emitterLedger` (`Float32Array(20)` = 80 B).
4. **Live substep `rhoMean`**: `config.paramsOff.rhoBase` (`95`) carries
   `(initialM + paintInjM) / (N * N)`, and `forces` computes
   `rhoMean = params.values[95] + (emitterLedger[0] - emitterLedger[5]) * invN * invN` every
   substep without waiting for `statsEvery`.
5. **Async readback pairing without `paintDye` races**: `statsReduceB` copies
   `emitterLedger[0..9]` into `stats[36..45]` (`STATS_LEN = 46`). At readback copy launch,
   `gpu/solver.js` snapshots `pendingEmitNet` from `emitNetKnown`; on `mapAsync` completion,
   `pollStats()` adjusts the paired `expected` snapshot by `emitNetGpu - pendingEmitNet` and
   advances live `expected` + `ledger.injected*`/`ledger.removed*` by `emitNetGpu - emitNetKnown`,
   preserving any CPU `paintDye` patches applied while the readback was in flight.
6. **Zero overhead when idle**: when `scalarCount == 0`, `encodePhaseChain` encodes neither
   `emitterTally` nor `applyEmitters` (`0` extra dispatches); when only `heat`/`cold`/`freeze`
   are active (`massDrainCount == 0`), `emitterTally` is skipped (`1` dispatch/substep);
   `setGrid()` / `resize()` re-uploads live emitter slots into the rebuilt pool, and `reset()`
   zeros `pool.emitterLedger` while keeping configured emitters active.
