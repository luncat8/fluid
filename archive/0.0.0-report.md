**The design in six decisions**

1. **MAC grid + variable-density pressure projection**, as you picked. Solids = frozen faces, pressure is a first-class output for the pressure view.
2. **Conservation by construction, not by fixup.** One `compute_flux` pass writes each face's volume flux exactly once; both neighbouring cells read that same float and apply it with opposite signs. Closed-box drift should then be *exactly* 0, not "small" — that's an acceptance criterion, and any nonzero number means a masked face is inconsistent. Conserved quantities ride fluxes (never semi-Lagrangian); only velocity gets semi-Lagrangian, since momentum isn't a tracked invariant.
3. **Energy E is the state, temperature is derived.** Latent heat then becomes a plateau in `T(E)`, so melting/boiling charge and release energy for free and the budget closes — that's how "keep energy and mass" is literally satisfied. Piecewise caloric EOS, evaluated from final E, never integrated incrementally.
4. **Your "aggregate" phase model, made concrete**: no free surface, no surface tension — just a density hierarchy vacuum < steam < water = ice, one velocity field, gravity sorts them. Gas compressibility = a divergence source `S = (ρ−ρ*)/(ρ·τ)` in the projection RHS, so boiling expands and pushes without a second solver. That answers the draft's open question: both, asymmetrically, cheaply.
5. **"Show color properly not/mix"**: donor-cell upwind first (monotone, exact), then Zalesak/FCT limiting in `0.3.1` — the correction is itself an antisymmetric flux difference, so sharpness improves ~3x while conservation stays exact. Clipping negatives is banned (it deletes mass); min-value watchdogs in the stats reduction instead.
6. **Core WebGPU only** — no optional features. Everything is ping-pong with write-only storage textures (`rgba32float` can't be `read_write` in core anyway), `textureLoad` for float32 (not filterable without a feature), an `rgba16float` display texture for bilinear upscale, hierarchical reductions (no f32 atomics), and all WGSL inline as JS strings because `fetch()` of local files dies on `file://`.
