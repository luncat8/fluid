### compressible or not?
(for simplicity we can simulate both water and gas same - it is ok for game now, but if not very difficult - better to have both). 

One solver, compressible gas only (my pick)
Liquid+solid enforced divergence-free; gas cells get a divergence source from heating/EOS so steam expands and pressure rises. Both behaviors, one pipeline, cheap.

Fully incompressible first
Gas = low-density smoke that does not expand. Simplest and fastest to a working milestone 1-3; expansion bolted on later.

Fully compressible everywhere
Explicit compressible solve with real pressure waves and sound speed. Most physical, hardest to keep stable at interactive dt (CFL limited by c).
