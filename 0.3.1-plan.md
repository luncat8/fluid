# 0.3.1 — fct flux limiting: sharp colors, still exactly conservative

status: planned (optional in sequence, required for the "not/mix" look)
depends on: 0.3.0
milestone: draft.txt milestone 1 quality bar

## 1. goal

donor cell upwind is monotone and exactly conservative but first order: a dye front
smears over ~sqrt(steps) cells. fct (flux corrected transport, zalesak limiter) adds an
anti diffusive correction that is itself a flux difference, so conservation from 0.3.0
stays exactly true while the front stays within a couple of cells. no negative values,
no new extrema, colors stay saturated.

## 2. design

### 2.1 quantities and bounds

limited quantities: m, dr, dg, db (as concentrations c_k = q_k / m) and E (as specific
energy e = E / m). limiting concentrations rather than raw densities is what keeps
ratios bounded, which is what "r+g = yellow, not brown" actually requires.

per cell, from the low order result q_L and m_L:
	c = q_L / max(m_L, m_eps)
	c_min, c_max over the 3x3 neighbourhood (clamped to the global initial range)
	Q_plus  = m_L * (c_max - c)      how much q may still be added
	Q_minus = m_L * (c - c_min)      how much q may still be removed

### 2.2 three passes (no correction storage, recomputation instead)

pass A advect_scalar (already exists) writes the low order q_L, m_L into the ping pong
destination.

pass B limiter_prepare, per cell:
	recompute the four face corrections from flux and the *source* slot values
	high order (lax-wendroff, |F| <= 1 so the coefficient is well defined):
		A_high(F, qL, qR) = F*(qL+qR)*0.5 - abs(F)*(1 - abs(F))*(qR - qL)*0.5
	low order:
		A_low(F, q_up) = F * q_up
	d(F) = A_high - A_low                    antisymmetric across the face by construction
	accumulate P_plus  = sum over faces of the part of d that adds to this cell
	accumulate P_minus = sum over faces of the part that removes from this cell
	R_plus  = min(1, Q_plus  / max(P_plus,  eps))
	R_minus = min(1, Q_minus / max(P_minus, eps))
	write (R_plus, R_minus) into a rg32float limiter texture

pass C limiter_apply, per cell:
	recompute d(F) for the four faces (identical inputs -> identical floats)
	for each face pick the receiving cell (sign of F decides) and use its R:
		r = (d adds to the receiver) ? R_plus(receiver) : R_minus(receiver)
		dlim = r * d
	also limit by the *sending* cell when it is the one losing more than allowed
	(both ratios, take the min — this is the standard zalesak two sided limit)
	q = q_L + sum of inflowing dlim - sum of outflowing dlim
	write to the final slot

each face's dlim is derived from the same flux value, the same source densities and the
same two R values by both adjacent cells, so the correction cancels exactly in the
global sum. conservation from 0.3.0 acceptance a2 must remain exactly 0 drift.

### 2.3 configuration

	fct_limiter in params: 0 = off (pure upwind), 1 = on
	hotkey toggles it live so the difference is visible side by side
	limiter texture: rg32float, one copy (written then read within the step)

### 2.4 plan b

if zalesak proves finicky with five coupled quantities, fall back to a per quantity
min-mod slope limited centered flux (still a face flux, still antisymmetric, still
conservative, slightly more diffusive than fct but much simpler). the acceptance
numbers decide: plan b is acceptable if it reaches 2x sharpness improvement instead
of 3x. record which one shipped in findings-pitfalls-skills.md.

## 4. acceptance

- a1 conservation unchanged: closed box drift_rel exactly 0 for all five invariants at
	10000 steps with fct on.
- a2 sharpness: dye front width after 500 steps at least 3x smaller than the 0.3.0
	upwind baseline (the number recorded in a7 of 0.3.0).
- a3 monotonicity: zero negative cells, zero new extrema (cell values never exceed the
	initial global range), zero overpacked cells.
- a4 three blobs stirred for 1000 steps: cores saturated, overlaps yellow/cyan/magenta,
	no brown.
- a5 cost: frame time increase below 30 % at N=1024 versus upwind only.
- a6 cfl: the limiter is only valid for |F| <= 1 per face; the 0.2.0 substep rule must
	guarantee it, and a watchdog counts faces with |F| > 1 (must stay 0).
- a7 outflow budget: FCT's anti-diffusive flux d(F) must compose within the k_out <= 1
	outflow limiter (0.0.0 section 5.1). total flux on a face is F_low + r*d(F); per-cell
	sum of outgoing total flux must stay <= 1 volume per step, otherwise the donor
	q'=q*(1-k)+in update leaves monotone regime even with Zalesak bounds. enforce by
	scaling dlim on outgoing faces so k_out(low)+k_out(dlim) <= 1, or by re-applying
	the 5.1 outflow limiter to the summed flux before the q update (still a single
	shared face value, so conservation untouched). watchdog: stored k_out after FCT
	must stay <= 1.

## 5. risks and pitfalls

- the two sided limit is what prevents clipping mass: limiting with only the receiver's
	ratio lets a sender go negative. use min of both.
- recomputing d in pass C must use exactly the same inputs as pass B. if pass B reads
	the source slot and pass C reads the destination slot, the numbers differ and
	conservation breaks. bind both passes to the same pair, comment it.
- Q_plus/Q_minus use the low order result, not the previous step's values; using stale
	bounds produces visible clipping at fast fronts.
- lax-wendroff needs |F| <= 1; above that the (1-|F|) term changes sign and the scheme
	becomes anti-diffusive in the wrong direction. the watchdog in a6 is mandatory.
- vacuum cells (m ~ 0) have meaningless concentrations: skip limiting there and fall
	back to plain upwind, otherwise c = q/m_eps explodes.
- extra passes cost bandwidth; at N=1024 measure before assuming it is free (a5).
- outflow budget: low-order k_out <= 1 is not enough once FCT adds dlim. a diverging
	cell with k_out(low)=1 can be pushed to k_out(total)=1+d_out > 1 by the correction
	and go negative next step even though Zalesak allowed it. budget the antidiffusive
	flux inside the 5.1 limiter: compute F_total = F_low + dlim, then scale outgoing
	F_total per cell to sum <= 1 (same pattern as compute_flux, each face's final flux
	remains the single shared value). without this composition FCT is not monotone at
	divergent draws.
