Fluid · browser GPU diagnostics

Runs the same WebGPU solver as index.html through the selected scenarios with fixed, serial frames. It records conservation, positivity, divergence, substeps and queue wait in one copyable report. The scripted draw/stir case repeats a dye stroke and mouse-force sweep over the blobs scene. Divergence and compression are measurements, not pass/fail gates. This is the real-device complement to node experiments/run-all.js.

For the browser's finer performance.now() resolution, serve this page with python3 run_browser_tests.py (or python3 run_index.py --page experiments/browser-tests.html). The server sets COOP/COEP; the report shows whether the page is cross-origin isolated and which timer quantum was observed. For the red-black baseline, run the same capture with --query "n=512&frames=600&scenarios=blobs,draw&mg=0"; grid, frame count and scenarios are otherwise identical.

Each run resets between scenarios and uses the app's auto-CFL policy, FCT, gravity, pressure iteration count and multigrid settings. Stats are sampled every 30 frames and at the end. Queue wait includes driver/scheduling overhead; it is not a GPU timestamp. Keep the tab visible during a run. ?n=512&frames=600&scenarios=blobs,draw selects the blob and scripted draw cases; append &mg=0 for the RB A/B and &auto=0&ns=4 for fixed four-substep runs. &k=, &cycles=, &pre=, &post=, &s= tune the pressure solve, and &profile=1 adds per-group GPU timestamps where the adapter supports them.
